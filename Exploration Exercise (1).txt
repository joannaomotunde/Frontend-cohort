Exploration Exercise
I checked LinkedIn, Gmail, and Instagram using the Inspect tool, and honestly, I was surprised by how much code is behind each page. On LinkedIn, I saw things like <div> and <img> tags. I know <img> is for images, and I could see the sizes, colours, and something called “visually hidden,” which I think is for accessibility. When I opened Gmail, the code started with <html lang="en">, I knew that meant the page was in English, and I saw many <div> classes and so many <script> tags repeating everywhere. Then on Instagram, the code was even more confusing. I kept seeing things like script type, data-content-len, data-sjs, and data-nonce appearing a lot. I also noticed “flex” written a few times near the end of some code. I don’t fully understand what all these mean yet, but it made me realize that websites are way more detailed and technical than they look on the surface.
